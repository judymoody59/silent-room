## T1 · feat: 도메인에 방·참가자·재실과 동물 이름 배정 규칙 구성

### 상위 Requirement

- relates to #3

### 작업 내용

- `com.judymoody59.silentroom.domain` 아래에 `Room`·`Occupant`·`Presence` 값 객체와 동물 이름
  열거형을 둔다. 명세 "개념 모델"·"표시 이름 정책" 대응
- 동물 이름 열거형이 곧 `occupantId` 다. `Occupant` 는 그 값 하나를 갖는다
- `Room` 은 `roomId` 와 현재 재실 명단을 내부 상태로 갖는다. 다음 규칙을 순수 함수로 노출한다
  - 주어진 방 상태에서 미사용 값 중 하나를 배정해 새 참가자를 추가하고 갱신된 상태를 반환
  - 주어진 방 상태에서 특정 참가자를 제거하고 갱신된 상태를 반환. 그 값은 다시 배정 가능해진다
  - 현재 재실 명단(`occupantId` 배열) 조회
- 배정 순서는 결정적(열거형 선언 순서 기준)으로 둔다. 무작위성을 넣지 않는다 — 테스트가 흔들린다
- `java.*` 외 import 를 두지 않는다. `script/verify-project.sh` 가 검사한다

### 작업 내용

- 유스케이스는 `roomId` 로 방을 찾아 (없으면 새로 만들고) T1 의 도메인 규칙을 호출한다. 방 상태

- 이벤트 페이로드는 `occupantId` 와 종류 두 필드뿐이다. 다른 필드를 더하지 않는다
